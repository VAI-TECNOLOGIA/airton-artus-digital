| `Manual-do-Sistema.html` | **Manual completo de uso do sistema** — todos os módulos, perfis de acesso, fluxos passo a passo, boas práticas/LGPD e FAQ (autocontido — abrir no navegador; Ctrl/Cmd+P gera PDF) |
